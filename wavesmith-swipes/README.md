# WaveSmith Swipes — v1.0

**Status: untested — shared as-is.**

For WaveSmith, the Powerhouse Apps audio editor. While audio plays and the waveform has focus: swipe left rewinds, swipe right fast-forwards, swipe up zooms in.

This one has not had its on-device test yet. If you try it, Justin's support mailbox (support@powerhouseapps.net) would genuinely like to hear how it went.

Download `wavesmith-swipes.lua` and import it into SandFly.
