# Thunderbird Keys and Actions — v1.3

**Status: final, verified.**

For Thunderbird for Android (`net.thunderbird.android`).

Desktop-style keyboard shortcuts: Ctrl+N new message, Ctrl+R reply, Ctrl+Shift+R reply all, Ctrl+L search, Delete, Space to select, SandFly+J to move between headers and body, SandFly+Enter to send. The message list also gets iOS-style actions — swipe right or left moves message to message, swipe down or up cycles actions, double-tap runs one (and toggles selection in selection mode).

Download `thunderbird-keys-actions.lua` and import it into SandFly.
