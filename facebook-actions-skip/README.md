# Facebook Actions and Skip — v1.6

**Status: final, in daily use.**

For the Facebook app (`com.facebook.katana`).

Swipe up or down on a post to cycle its actions (Like, Comment, Share, and the rest), then double-tap to run the one you picked. SandFly+J — or a two-finger swipe right — skips the trapping sections (Stories, Reels, People You May Know) and lands on the next post.

Download `facebook-actions-skip.lua` and import it into SandFly.
