# Play Protect Install — v1.0

**Status: final, verified working.**

For the Google Play Protect scan prompt that appears when installing apps from outside the Play Store.

Press Alt+I and the script chooses "Install without scanning" for you, then puts focus in the PIN field so you can finish the install by keyboard.

Only use this if you already scan and trust what you install — Justin lets Play Protect scan his own apps first (the scan report is published with every Powerhouse Apps release) and uses this for the keyboard flow, not to dodge the check.

Download `play-protect-install.lua` and import it into SandFly.
