# SandFly Scripts

Scripts for the [SandFly](https://github.com/aaron-gh/SandFly) screen reader for Android, written for Justin Harris's workflow.

Justin says:

> I made these for my workflow — made for me first. If they help you, awesome. If not, have your AI of choice cook something up for you.

## How to use a script

1. Open the script's folder above and download its `.lua` file.
2. In SandFly, import the file and enable the script.
3. Each script only runs in the app it was built for — the README in its folder says what it does, its keys and gestures, and how well it has been tested.
